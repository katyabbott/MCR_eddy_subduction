# MCR_eddy_subduction
Code to reproduce the figures and main conclusions in "Microbial respiration regulates the fate of eddy-subducted organic carbon in the mesopelagic ocean" (Abbott et al.). Code is written in Python and is organized into folders for analysis of respiration rates (Respiration), analysis of hydrographic data (Hydrographic) or analysis of flow cytometry data (Flow_cytometry).
